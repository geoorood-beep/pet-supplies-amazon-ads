# 匹配类型竞价排序

备案日期：2026-11-14

## 采用的顺序

四档，从高到低：

**精准 > 词组 > 广泛 > 自动**

精准最高，自动最低。这是竞价优先级，也是低价承接的方向：已验证的词用更高竞价承接，更宽的匹配用更低竞价去接剩余流量。

2026-11-14 记录写明，出处是总纲 §8.6「默认范围瀑布流」。

## 总纲 §8.6 原文

> 这里的 `精准 → 词组 → 广泛 → 自动` 是竞价优先级和低价承接方向；第 7.4 节的 `AUTO → 扩词 → 精准` 是数据发现和搜索词晋级方向，两者不是同一个箭头。

两个箭头不要合成一条：

| 箭头 | 方向 | 回答的问题 |
|---|---|---|
| §8.6 | 精准 → 词组 → 广泛 → 自动 | 谁的竞价更高，谁去接更低价的剩余流量 |
| §7.4 | AUTO → 扩词 → 精准 | 数据从探索走向已验证搜索词 |

§8.6 同时写明：同词、同匹配方式的多 Bid 瀑布流不是默认结构。只有该词已有稳定搜索词和订单、最高层能持续花费且达标、新层用来承接剩余低价流量、活动预算和广告位能够隔离、且新层不会明显拆散数据或内部抬价时，才进入候选。是否加下一层，取决于上一层是否能花费、表现达标、仍有增量空间。

## 总纲 §7.2 的倍率与 §8.6 重叠

§7.2 的原则原文是：

> 精准 Bid > 词组/广泛 Bid > 自动广告 Bid

它把词组和广泛写在同一档，没有写成「词组高于广泛」。在「假设自动广告基础竞价为 `x`」之下，暂定倍率是：

| 投放方式 | 总纲 §7.2 暂定 Bid | 标记 |
|---|---:|---|
| 自动广告 | `x` | 与 2026-11-14 的锚点定义不同，见下一节 |
| 广泛匹配 | `1.1–1.2x` | 变量 / 示例 |
| 词组匹配 | `1.1–1.3x`，根据词根层级确定 | 变量 / 示例 |
| 精准匹配 | `1.3–1.4x` | 变量 / 示例 |

广泛 `1.1–1.2x` 与词组 `1.1–1.3x` 的区间重叠。只用这两段数字，不能推出「词组一定高于广泛」。§8.6 给出的是顺序，§7.2 给出的是一组互相重叠的暂定区间。2026-11-14 采用的是 §8.6 的四档顺序；§7.2 的区间保持为总纲里的暂定模板，按变量处理，不作为已经分开的执行倍率。

总纲第十四章第 7 条和第 8 条仍待补充：不同词级下广泛和词组的 Bid 关系，以及词根、匹配方式、搜索量等多个系数如何叠加。在补充之前，不能把词根阶梯和匹配类型阶梯乘成一套新倍率。

## 锚点以 2026-11-14 为准

2026-11-14 把关键词竞价层级的锚点定为一级词 = `x`，自动广告用 `0.x` 占位，具体值待测。

因此 §7.2 里「自动广告基础竞价为 `x`」只保留为总纲当时的假设，不再作为当前锚点。当前已定的是：一级词为 `x`，自动低于一级词，记成 `0.x`。`0.x` 还没有测出具体值，不能填成 `0.8`、`0.9` 或其他导图里出现过的数。

词根层级仍是另一条轴。总纲 §7.1 的原则是：一级词 Bid < 二级词 Bid < 三级词 Bid。它和匹配类型的四档是两套关系。两套如何叠在一起，属于上面的待补充项。

## 两份导图都没有把词组和广泛分开

新旧两份导图都没有把词组和广泛分成两档，而是写成「广泛/词组」或「广泛词组」同一档，再按一级、二级、三级词分高低。

新版导图里可以同时看到多套数字，例如架构模型里的 `AUTO-X / 广泛词组一级词-1.1x / 精准-1.2X`，以及「投放词缩放量」里的 `自动-0.8x / 一级词-0.9x / 二级词-1.0x / 三级词-1.1x / 精准-1.2x`。这些数字说明新版自己也不统一，所以 2026-11-14 不采用其中任何一套阶梯，只采用四档顺序，并把倍率视为变量。对照见 [03-新旧导图冲突对照.md](03-新旧导图冲突对照.md) 第 1 条。

旧版导图另有一句：「长尾广泛竞价要高于大范围广泛10%」（`../source/soju培训_大纲.txt` 对应行：长尾广泛竞价要高于大范围广泛10%）。这句话只在旧版出现。它是广泛内部的相对关系，不是词组和广泛的分档。其中的 10% 是具体数字，按 2026-11-14 的总口径视为变量，本次没有把它收成执行规则。
