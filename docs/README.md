## 执行边界

本目录不能自动执行，也不能据此直接改广告。

1. 总纲第十四章有 30 条「尚待补充的核心规则」。补充确认之前，这 30 条不是已授权的自动执行规则，只允许提示或进入人工复核。
2. 只有负责人明确说「确定搭建」之后，才进入 AGENTS 搭建阶段。在此之前不搭建 AGENTS、不写执行脚本、不创建广告活动。
3. 竞价倍率、分数阈值、预算倍数等具体数字按品类实测，见 02。文件里出现的数字是变量或示例，不是全类目常数。
4. 以下 4 项即使框架已记录，也不能填一个数后自动执行：自动广告相对一级词的 `0.x`（待测）、VCPM 归因范围（待核实）、广告位「基于规则」倍率（待补充）、第十四章其余未补充项。
