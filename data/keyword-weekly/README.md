# 每周关键词扫描（keyword-weekly）

本目录存放西柚洞察每周一扫描的结果，品类目前是美国站狗喂水器。只做记录，不覆盖 Notion 准词表里的静态字段，也不在亚马逊后台改广告。

## 命名约定

- 按 **ISO 周** 归档，每周一份 Markdown 报告和一份机器可读 CSV，文件名形如 `2026-W45_狗喂水器.md` / `2026-W45_狗喂水器.csv`。
- 周次对应的是 ABA 数据周（通常接近该 ISO 周），具体起止日期写在当周 md 的文首。例如 `2026-W45` 对应 ABA 周 2026-11-01～11-07。
- Markdown 给人看，包含飙升/新词/增长词、静态准词表修正、广告优先级，以及建议否定或降级的词。
- CSV 给程序用，字段见下。

## CSV 字段

| 列 | 说明 |
|---|---|
| 关键词 | 亚马逊关键词，保留英文 |
| 本周搜索量 | ABA 当周周搜索量 |
| 周环比 | 相对上一周，小数（0.33 表示 +33%） |
| 近4周vs前3周 | 近 4 周周均相对再往前 3 周周均，小数 |
| 静态搜索量 | 准词表里的搜索量（原值，不在本目录改写准词表） |
| 静态得分 | 准词表竞品表现得分（原值） |
| 历史广告订单 | 准词表或历史广告汇总中的订单数 |
| CPA | 历史广告 CPA（美元） |
| 类别 | 飙升 / 新词 / 增长 / 过时 / 需评分 / 否定 |
| 建议匹配 | 精准 / 词组 / 广泛 / 否定 / 观察 |
| 优先级 | 建议投放的优先顺序，数字越小越优先；可选测试词用较大数字 |
| 备注 | 补充说明 |

## 与准词表的关系

- Notion 同步过来的准词表静态列（搜索量、得分等）**一律不在本目录或 `data/notion/` 里覆盖**。原件仍以 `data/notion/` 和 Notion「词库」页面为准。
- 发现静态数据需要修正时，写入当周文件，并追加到 [词库修正记录.md](词库修正记录.md)。修正记录是变更日志，不是新的准词表。
- 修正记录字段：日期、关键词、原值、新值、原因。

## 更新节奏

每周一 9:00（北京时间）西柚扫描跑完后，新增当周 md+csv，并把新的修正追加进修正记录。同期在 Notion「每周关键词更新表」写入同一批关键词。广告调整要等负责人确认后再执行。
