# pet-supplies-amazon-ads

宠物用品亚马逊广告知识库，站点为美国，品类是狗、猫喂水器。内容来自 2026-11-14 锦浩 郑和 Amzon员工通话时确认的广告架构知识。

## 口径优先级
1. 2026-11-14 通话确认的口径，见 `docs/02`。
2. 《亚马逊广告推广架构总纲 V2.0 确认版》，原文在 `source/`。
3. 新版导图《Soju亚马逊高阶课笔记20260723》的逻辑框架。

具体数字（竞价倍率、辅推倍率、准词分数阈值、预算等）一律当变量，按品类实测。总纲第十四章里 30 条尚待补充的规则不能自动执行；锦浩明确说「确定搭建」后，才进入 AGENTS 搭建阶段。本仓库只放文档和数据，不在亚马逊后台做任何操作。

## 狗、猫初版架构要点
- **狗**：准词以 6 分以上为主，用标准版。先跑三条测试线：AUTO 紧密（0.x）；一级词广泛（x），测 dog water fountain 等词根；精准（1.x），测历史出过单的词。
- **猫**：核心大词只有 4 分，先用简单测试版，同时校准 4 分算不算准词。对比 4 分大词和 8 分无线词的转化。
- **两个品类**：测试期用固定竞价，每个活动预算按 3–5 个目标 CPA 留。售价、毛利、ASIN 等输入还要锦浩补充。
